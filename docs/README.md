# Urasil_light

Urasil_light ist ein modular aufgebautes, organisch reagierendes KI‑Kernsystem.  
Es kombiniert zyklische Zustände, Wertorientierung, Reife‑Filter und eine mehrstufige Antwortpipeline zu einem lebendigen, dynamischen Verhalten.

Das System ist bewusst leichtgewichtig gehalten, aber intern hochgradig strukturiert.  
Es eignet sich als Grundlage für experimentelle KI‑Persönlichkeiten, adaptive Chat‑Systeme oder kreative Agenten.

---

## ✨ Kernprinzipien

Urasil_light basiert auf vier zentralen Ideen:

### 1. **Zyklus**
Ein innerer Rhythmus aus Sonne, Mond und Tag bestimmt:
- Stimmung  
- Fokus  
- Tiefe  
- Stil  

### 2. **Pipeline**
Jede Antwort durchläuft:
1. Interpretation  
2. Seed (Rohantwort)  
3. Silky Edge (Stil)  
4. Reflexion  
5. Erfahrung  

### 3. **Werte**
`gold.txt` definiert Idealwerte wie:
- Klarheit  
- Integrität  
- Resonanz  
- Tiefe  

### 4. **Reife**
`ininity.txt` filtert unreife oder unpassende Erfahrungen heraus.
